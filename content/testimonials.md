## Transcript intake template

Copy this block for every new client transcript.

```md
## Client name

**Status:** TRANSCRIBED / APPROVED FOR ADS / ANONYMISE
**Role or business:**
**Offer used:**
**Timeframe:**
**Source asset:**

### Verbatim transcript

Exact wording here. Do not clean up grammar inside the verbatim section.

### Approved pull-quotes

- “Short, exact quote.”

### Claim context

- Starting point:
- What changed:
- Observable result:
- Timeframe:
- Necessary qualification or disclaimer:

### Proof tags

`inbound` `revenue` `authority` `content` `sales-call` `analytics`
```

## Usage rules

1. Keep the verbatim transcript exact; edits belong only in approved pull-quotes.
2. Never infer a result from a filename alone.
3. Pair revenue or performance claims with timeframe and context.
4. Do not promise identical results. Use “results like this”, “the system behind this”, or “how this happened”.
5. Do not use client photos publicly unless Radical Edge confirms permission for that asset.
6. Redact private names, phone numbers, contact details, payment references, and confidential business information.
